YOUR TASK — V1 COMPACT TRADE UPDATE:
================================================================================
Using REAL-TIME search (news + filings + live price data), generate a concise
institutional-grade trade update with exactly these 4 sections:

1. 📊 Market & Technical Snapshot
   - Current price vs VWAP, Day High/Low
   - Short-term trend, key support/resistance, RSI/MACD state if material
   - Is the stock extended? Pullback entry recommended?

2. 📰 News & Filings Audit
   - Live news, exchange announcements, bulk/block deals for {symbol}
   - Macro/sector catalyst today
   - Label each: CONFIRMED / REPORTED / UNVERIFIED

3. 🧠 Wyckoff / VSA Assessment
   - Institutional phase: Accumulation / Markup / Distribution / Markdown
   - Volume vs price action — smart money accumulating or distributing?
   - Probability: Bullish X% / Base Y% / Bearish Z% (must sum to 100%)

4. 🎯 Actionable Verdict
   - Decision: HOLD / TRAIL SL / PARTIAL EXIT / EXIT
   - Exact price levels for every action
   - Time-based exit if target not hit by [state session/date]
   - Invalidation: price-based condition + event-based condition that cancels the thesis

5. ⚠ Risk & Execution Check
   - Liquidity/Volume: Is there enough volume for safe execution? (Flag if illiquid)
   - Risk:Reward: Is the R:R actually justifiable? (If poor, recommend WAIT)
   - Gap/Event Risk: Any impending earnings or macro events that could gap the stock?
